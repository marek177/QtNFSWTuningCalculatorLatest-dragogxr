# QtNFSWTuningCalculatorLatest-dragogxr

Original Qt NFS World tuning calculator repository.

## NFSWPerformanceTool algorithm update

The newer 12-value NFSW performance calculation has been prepared for this Qt calculator, including Tuner, Analyzer/Finder, Maximizer, compare and diagram paths.

Because the original C++ source in this repository is stored inside `QtNFSWTuningCalculatorLatest.rar`, the update is provided as ordered unified patches in:

`updates/NFSWPerformanceTool-algorithm/`

See `updates/NFSWPerformanceTool-algorithm/README.md` for the algorithm details, supported cars, fallback behavior, and patch order.
